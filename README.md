# Figma Mixer

Плагин Figma для подготовки наборов векторной графики и создания композиций. Реализованы создание и пополнение наборов, композиции и пользовательские палитры.

## Запуск

1. Из исходников сначала собрать папку `dist` по инструкции ниже. В Figma Desktop открыть редактируемый файл.
2. Plugins → Development → Import plugin from manifest… → выбрать `dist/manifest.json`.
3. Запустить Figma Mixer. Уже подключённый плагин достаточно перезапустить.

Библиотека и палитра находятся над блоком запроса. Внутри доступны текст, плашки предметов, количество вариантов, формат и детализация. Запрос сразу создаёт варианты на холсте. Точный состав задаётся в режиме «Предметы». Управление библиотеками доступно под блоком. [Создание композиции по описанию](docs/user-flow.md).

## Создание набора

- Выделить целые объекты в Figma и выбрать «Из выделения Figma», либо открыть «Создать набор» и загрузить несколько SVG.
- Один выделенный объект или SVG-файл становится одним элементом. Внутренние векторы не разделяются.
- Проверить миниатюры, исправить названия, исключить лишние карточки, указать название набора и сохранить.
- Для одного контейнера доступен явный переход к его непосредственным вложенным объектам. Нативный Component Set Figma сохраняется одним элементом с вариантами.
- Существующий набор пополняется через «Добавить элементы». Название и свойства вариантов можно изменить в карточке элемента.
- Несколько карточек можно отметить и объединить как варианты одного элемента. Их геометрия сохраняется.

Наборы содержат независимые копии исходников на странице «Mixer · Библиотека». Метаданные записываются в документ Figma. Изменения исходной графики не синхронизируются автоматически. Экспорт набора в JSON и обратный импорт переносят графику и метаданные между документами.

## Композиции

- **Предметы**. Введите названия через запятую или добавьте их кнопкой «+». Подсказки помогают выбрать точное имя. Состав собирается локально, в том числе с палитрой «Авто».
- **Идеи**. Введите заголовок или метафору. AI выбирает предметы из текущей библиотеки. Чтобы закрепить предмет во всех вариантах, добавьте его через `@`.

Под полем запроса выбираются формат, детализация S/L, построение и количество вариантов. Один запуск создаёт от 1 до 12 редактируемых фреймов из 1–8 предметов каждый. В режиме «Предметы» монохромную версию можно выбрать через кнопку «Добавить фоном» у предмета. В режиме «Идеи» роли предлагает модель.

Фреймы появляются на странице «Mixer · Композиции». На холсте Figma можно перемещать, поворачивать, дублировать и удалять предметы, а также менять порядок слоёв. Миниатюры последнего запуска появляются под запросом и синхронизируются с выделением Figma. Щелчок выбирает фрейм, Shift + щелчок добавляет его к выделению. Для скачивания выберите один фрейм и нажмите «Экспорт SVG». Фрейм также доступен для нативного экспорта Figma.

Генератор подбирает раскладку по площади силуэтов, контрасту, деталям и перекрытиям. Для анализа Figma временно экспортирует PNG. На холст копируются исходные векторные узлы с общим масштабом, поэтому их относительные размеры сохраняются. L и S загружают готовые версии из библиотеки. Изображения анализа остаются внутри плагина.

Встроенные и пользовательские схемы перекрашивают предметы стартовой библиотеки при создании композиции. Для готовых фреймов откройте «Перекрасить композицию», выберите или импортируйте палитру. Результат виден сразу на холсте, «Применить» сохраняет его. При выборе нескольких фреймов их исходные палитры должны совпадать. Цвета загруженных пользователем SVG сохраняются. Формат JSON и работа с редактором описаны в [документации палитр](docs/palettes.md).

## Подключение AI

Для режима «Идеи» настройте DeepSeek, OpenAI или OpenAI-совместимый сервис. Введите собственный API-ключ и выберите модель. Ключ действует до закрытия плагина. Адрес, провайдер и модель сохраняются локально. Подробности в [инструкции подключения](docs/ai-connection.md).

## Проверки

Модульные тесты покрывают библиотеку, планы генерации, раскладку и цвета. Браузерные тесты запускают реальный интерфейс и планировщик с подменой Figma и ответа AI. Проверяются оба режима, импорт SVG, выбор и сохранение палитр, скачивание SVG, обработка ошибок и настройки подключения.

На предыдущих сборках в Figma Desktop проверялись импорт выделения и SVG, сохранение набора, создание и экспорт векторных фреймов, повторный импорт SVG и генерация через DeepSeek. История прежнего мастера и его проверок сохранена в ветке `archive/manual-item-picker`. Пример проверки DeepSeek приведён в [сценарии генерации](docs/user-flow.md).

## Ограничения

- SVG для импорта должен быть автономным вектором. Текст нужно перевести в кривые. Один файл становится одним предметом.
- Анализ силуэта выполняется на сетке 24 × 24. На сложных сочетаниях может понадобиться ручная правка на холсте.

## Разработка

Node.js, TypeScript, React, esbuild, Vitest. После установки зависимостей:

```powershell
node scripts/run.mjs typecheck
node scripts/run.mjs test
node scripts/run.mjs ui-test
node scripts/run.mjs build
```

Установка: `node scripts/run.mjs install`. Загрузки npm и кэши Vitest направлены в проектную `.cache`. Запускатель скрывает дочерние процессы Windows, закрепляет threads и скрывает вспомогательную проверку сетевых дисков Vite.

`scripts/prepare-assets.py` повторно собирает стартовую библиотеку из ранее выгруженных материалов SnapBuild по локальному пути; для обычной сборки запускать его не нужно, готовые данные входят в `src/assets`.

Визуальная проверка раскладки: `node scripts/preview-layout.mjs`, затем `node scripts/render-svg.mjs .cache/qa/layout-gallery.svg .cache/qa/layout-gallery.png 1160`. Требуются Python с Pillow и установленный Inkscape по пути `C:/Program Files/Inkscape/bin/inkscape.exe`. Галерея содержит девять сочетаний исходных предметов в трёх форматах, включая несколько фоновых версий, и использует анализ их растеризованных силуэтов. Временные SVG, PNG и профиль Inkscape находятся в проектной `.cache`.
