# Палитры

Оформление → «Палитры» открывает редактор перекраски. Выберите существующую схему или нажмите плюс, чтобы начать на основе текущих цветов. Пары образцов показывают исходный цвет библиотеки и его замену. Метка «Фон» означает, что цвет можно использовать и в фоне, и в предметах; остальные цвета доступны только предметам.

Нажмите пару, измените цвет в компактном пикере и подтвердите кнопкой «Готово». Escape закрывает пикер. Предпросмотр меняется сразу, холст до подтверждения остаётся прежним. Для выделенной композиции используется SVG временной копии сцены; копия удаляется после экспорта. Если композиции ещё нет, показан подписанный пример из выбранных предметов.

- «Применить» перекрашивает выбранную композицию. Её координаты, размеры, внутренние части и прозрачность сохраняются.
- «Использовать» выбирает оформление будущих композиций. В редакторе существующей сцены для этого есть «Использовать для новых композиций».
- «Сохранить как палитру» запрашивает название и добавляет схему в текущий документ. Само сохранение не меняет уже созданную сцену.
- «Сохранить изменения» обновляет ранее созданную пользовательскую палитру. Существующие композиции обновляются отдельно через «Применить».
- Закрытие редактора отменяет неподтверждённые изменения. Применённую без сохранения схему можно использовать в текущей сессии; для следующего открытия документа её нужно сохранить как палитру.

Импорт и экспорт JSON находятся в меню с иконкой настроек рядом с выбором палитры. Импорт сначала показывает цвета для проверки; запись в документ выполняется при сохранении. Встроенные схемы не изменяются: на их основе создаётся пользовательская схема. Цвета могут повторяться в разных назначениях.

## Формат файла

```json
{
  "version": 1,
  "name": "Моя палитра",
  "background": ["#D7CDF5", "#AA9BF0", "#7864D7"],
  "object_accents": ["#F9ECB0", "#F9A3AA", "#FFE3E1"],
  "ink": "#181817",
  "paper": "#FFFFFF"
}
```

`background` содержит ровно три цвета, разрешённых в фоне и предметах. `object_accents` содержит три цвета только для предметов. `ink` заменяет цвет контура и тёмных деталей, `paper` — светлых деталей. Название: 1–100 символов. Цвета принимаются как `#RGB` или `#RRGGBB`, при сохранении нормализуются в `#RRGGBB`. Максимальный размер файла — 64 КБ. Идентификатор документа в экспорт не входит: импорт создаёт новую пользовательскую палитру.

Соответствия цветов известны для предоставленной стартовой библиотеки. Произвольные импортированные SVG сохраняют свои цвета. Привязка к переменным, стилям и командным библиотекам Figma не реализована.

## Проверки

40 модульных тестов покрывают в том числе формат, хранение, замену цветов, ограничение фона, применение несохранённой схемы, восстановление исходных цветов и очистку временной копии предпросмотра. `node scripts/run.mjs ui-test` запускает 9 сценариев DnD и 5 групп браузерных проверок палитр: создание, применение, повторное открытие, редактирование, импорт/экспорт, ошибки, отмена и узкая панель.

В Figma Desktop создана палитра «Мята · пример» и перекрашена композиция из пазлов, книги и телефона. Сравнение SVG до/после подтвердило неизменность геометрии и структуры 273 элементов, замену 21 вхождения цвета и отсутствие растровых вставок. После перезапуска плагина палитра снова доступна для выбора. Экспорты и снимки находятся в локальной `.cache/qa` и не входят в репозиторий. Figma MCP и Codex Computer Use не использовались.
