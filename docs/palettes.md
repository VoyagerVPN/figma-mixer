# Палитры

Селектор «Палитра» → «Настроить палитры…» открывает настройку цветов будущих композиций в расширенном окне. Внутри селектора можно выбрать схему, создать новую на основе текущей, сохранить копию или переименовать пользовательскую палитру. Пары образцов показывают исходный цвет библиотеки и его замену. Группа «Фон и предметы» содержит три фоновых цвета; группа «Только предметы» — три акцента, контур и светлые детали.

Выберите пару и измените цвет в постоянном редакторе справа: поле оттенка и насыщенности, вертикальная яркость, HEX. Между цветами можно переключаться без закрытия редактора. Подписанный пример с выбранными предметами обновляется сразу. Существующие объекты на холсте не меняются.

- «Использовать» выбирает оформление следующей генерации.
- «Сохранить палитру» в футере запрашивает название и добавляет схему в текущий документ. После записи она появляется в селекторе; редактор остаётся открытым.
- «Сохранить изменения» обновляет ранее созданную пользовательскую палитру и позволяет изменить её название.
- При закрытии крестиком, Escape или кликом по подложке, смене палитры, создании или импорте поверх изменений предлагаются «Сохранить», «Не сохранять» и «Продолжить редактирование». После успешной записи продолжается исходное действие; ошибка оставляет цвета и название в редакторе.
- «Использовать» допускает несохранённую схему для текущей сессии; для следующего открытия плагина её нужно сохранить в документ.

Импорт и экспорт JSON имеют отдельные иконки рядом с селектором. Импорт сначала показывает цвета для проверки; запись в документ выполняется при сохранении. Перед экспортом изменённую схему нужно сохранить. Встроенные схемы не изменяются: на их основе создаётся пользовательская схема. Цвета могут повторяться в разных назначениях.

Футер с действиями не прокручивается вместе с содержимым. При 760 × 900 и 400 × 760 редактор помещается без прокрутки тела; на низком экране прокрутка остаётся в теле, а действия всегда видны. Длинный список палитр имеет тонкий скроллбар; его команды не обрезаются футером. Выделение текста доступно в полях ввода.

В режиме «Пусть AI выберет» модель выбирает существующую палитру документа для каждого смыслового варианта. При выборе конкретной схемы все варианты используют её. AI не придумывает цвета вне схемы.

## Формат файла

```json
{
  "version": 1,
  "name": "Моя палитра",
  "background": ["#D7CDF5", "#AA9BF0", "#7864D7"],
  "object_accents": ["#F9ECB0", "#F9A3AA", "#FFE3E1"],
  "ink": "#181817",
  "paper": "#FFFFFF"
}
```

`background` содержит ровно три цвета, разрешённых в фоне и предметах. `object_accents` содержит три цвета только для предметов. `ink` заменяет цвет контура и тёмных деталей, `paper` — светлых деталей. Название: 1–100 символов. Цвета принимаются как `#RGB` или `#RRGGBB`, при сохранении нормализуются в `#RRGGBB`. Максимальный размер файла — 64 КБ. Идентификатор документа в экспорт не входит: импорт создаёт новую пользовательскую палитру.

Соответствия цветов известны для предоставленной стартовой библиотеки. Произвольные импортированные SVG сохраняют свои цвета. Привязка к переменным, стилям и командным библиотекам Figma не реализована.

## Проверки

51 модульный тест покрывает в том числе формат, хранение, замену цветов, ограничение фона, применение несохранённой схемы, восстановление исходных цветов и очистку временной копии предпросмотра. `node scripts/run.mjs ui-test` включает 8 групп браузерных проверок палитр: постоянный редактор, несохранённые изменения, сохранение перед закрытием и переключением, переименование, импорт/экспорт, клавиатуру и перетаскивание, узкое и низкое окно, длинный селектор и ошибку записи. Проверки выполняются в Edge без видимого окна; фактическое изменение размеров окна Figma Desktop в этом проходе отдельно не проверялось.

Пользовательские схемы хранятся в документе и доступны после перезапуска плагина. В текущем сценарии палитра настраивает будущую генерацию; ручная доработка готовой композиции выполняется в Figma. Проверка пути генерации описана в [user-flow.md](user-flow.md). Figma MCP и Codex Computer Use не использовались.
