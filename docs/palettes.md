# Палитры

На шаге «Параметры генерации» → «Оформление» → «Палитры» открывается настройка цветов будущих композиций. Выберите существующую схему или нажмите плюс, чтобы начать на основе текущих цветов. Пары образцов показывают исходный цвет библиотеки и его замену. Метка «Фон» означает, что цвет можно использовать и в фоне, и в предметах; остальные цвета доступны только предметам.

Нажмите пару, измените цвет в компактном пикере и подтвердите кнопкой «Готово». Escape закрывает пикер. Подписанный пример с выбранными предметами обновляется сразу. Существующие объекты на холсте не меняются.

- «Использовать» выбирает оформление следующей генерации.
- «Сохранить как палитру» запрашивает название и добавляет схему в текущий документ.
- «Сохранить изменения» обновляет ранее созданную пользовательскую палитру.
- Закрытие редактора отменяет неподтверждённые изменения. Несохранённая схема доступна в текущей сессии; для следующего открытия плагина её нужно сохранить как палитру.

Импорт и экспорт JSON находятся в меню с иконкой настроек рядом с выбором палитры. Импорт сначала показывает цвета для проверки; запись в документ выполняется при сохранении. Встроенные схемы не изменяются: на их основе создаётся пользовательская схема. Цвета могут повторяться в разных назначениях.

## Формат файла

```json
{
  "version": 1,
  "name": "Моя палитра",
  "background": ["#D7CDF5", "#AA9BF0", "#7864D7"],
  "object_accents": ["#F9ECB0", "#F9A3AA", "#FFE3E1"],
  "ink": "#181817",
  "paper": "#FFFFFF"
}
```

`background` содержит ровно три цвета, разрешённых в фоне и предметах. `object_accents` содержит три цвета только для предметов. `ink` заменяет цвет контура и тёмных деталей, `paper` — светлых деталей. Название: 1–100 символов. Цвета принимаются как `#RGB` или `#RRGGBB`, при сохранении нормализуются в `#RRGGBB`. Максимальный размер файла — 64 КБ. Идентификатор документа в экспорт не входит: импорт создаёт новую пользовательскую палитру.

Соответствия цветов известны для предоставленной стартовой библиотеки. Произвольные импортированные SVG сохраняют свои цвета. Привязка к переменным, стилям и командным библиотекам Figma не реализована.

## Проверки

40 модульных тестов покрывают в том числе формат, хранение, замену цветов, ограничение фона, применение несохранённой схемы, восстановление исходных цветов и очистку временной копии предпросмотра. `node scripts/run.mjs ui-test` запускает 9 сценариев DnD и 5 групп браузерных проверок палитр: создание, использование при генерации, повторное открытие, редактирование, импорт/экспорт, ошибки, отмена и узкая панель; дополнительно выполняются сценарии пути создания композиции.

Пользовательские схемы хранятся в документе и доступны после перезапуска плагина. В текущем сценарии палитра настраивает будущую генерацию; ручная доработка готовой композиции выполняется в Figma. Проверка пути генерации описана в [user-flow.md](user-flow.md). Figma MCP и Codex Computer Use не использовались.
